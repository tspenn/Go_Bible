# Magazine → Go-Bible deep links

Go-Bible: https://go-bible.com  
Magazine: https://faith.skylandpublishing.com

## Verse links from magazine articles

```
https://go-bible.com/bible/{book-slug}/{chapter}/{verse}
```

Examples:

- 2 Corinthians 5:7 → https://go-bible.com/bible/2-corinthians/5/7
- John 3:16 → https://go-bible.com/bible/john/3/16
- Psalm 23:1 → https://go-bible.com/bible/psalms/23/1

Book slug rules: lowercase, spaces to hyphens, keep leading numbers  
(`1 Peter` → `1-peter`, `Song of Solomon` → `song-of-solomon`).

Optional hash highlight: `/bible/john/3/16#v16`

## Topic links

```
https://go-bible.com/topics/{slug}
```

Seed slugs: faith, walking, grace, prayer, hope, trust, gratitude, home, sabbath, garden

## What Lovable should do after Go-Bible is live

```html
<a href="https://go-bible.com/bible/2-corinthians/5/7">2 Corinthians 5:7</a>
```

Do not embed Go-Bible inside the magazine. Link out.

Scripture in Go-Bible is the World English Bible (WEB), LORD edition to come.  
Do not use NIV, ESV, NASB, NLT, Vine, Wuest, or the 1967 New Scofield.
