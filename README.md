# Go-Bible

Look Up · Walking By Faith Companion (Skyland Publishing).

- App: this repo, deployed on Vercel
- Magazine: https://faith.skylandpublishing.com

## Features

- Full Go-Bible text (WEB base, divine name rendered LORD)
- Verse tabs: Scripture · Scofield 1917 · Henry · Dictionary · Topics · Robertson
- Strong’s 1890 long-press on seeded words
- Matthew Henry complete commentary seed notes
- A. T. Robertson, Word Pictures, vols. 1–3 (1930) — Matthew, Mark, Luke, Acts
- Dusty-blue / cream styling

## Run

```bash
pnpm install
pnpm run dev
```

Try `/bible/2-corinthians/5/7` and `/topics/faith`

See `DEEP_LINKS.md` for magazine verse links.
